# Gebruik van AI

Tijdens dit project (MusicAll Charts, CMTPRG02-5 Web Application Frameworks) heb ik AI (Claude van Anthropic) gebruikt voor twee onderdelen. Alle overige code, zoals de controllers, models, migrations, routes, validatie en logica, heb ik zelf geschreven.

## 1. Styling met Tailwind CSS

Ik heb Claude gevraagd om alleen Tailwind CSS-classes toe te voegen aan mijn bestaande Blade-views, zonder de PHP-code, Blade-directives of structuur te wijzigen. Het gaat om de volgende bestanden:

- `layout` en `navlink` componenten
- Home-, About- en Contact-pagina (inclusief dummy-inhoud)
- Index-, create- en edit-views van musicals, artists, albums en songs
- Dashboard
- Filterbalk en tabs op de songs-index

Het kleurenthema (donkerrood, goud en bijna zwart) en de opmaak van de kaarten en formulieren zijn door de AI voorgesteld. Ik heb de resultaten gecontroleerd en in mijn project gebruikt.
